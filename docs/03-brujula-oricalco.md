# Brújula Oricalco

**Status: IN DEVELOPMENT**

Oricalco is the personal edition of [Brújula](02-brujula.md): a smart layer for an individual's own Linux computer, aimed at clear explanations and safe, reversible actions.

## State

- Development is in an early milestone. The first milestone has been validated.
- Verified 2026-11-11: the edition's automated project checks pass in an isolated copy. Scope: code-level checks only. The virtual-machine and security-service parts were not validated in that run.
- A personal-edition image has been built from the Brújula codebase. A standalone Oricalco distribution is not available.

## Not yet decided or proven

Licensing and distribution terms are not decided. No installable standalone system is released.
