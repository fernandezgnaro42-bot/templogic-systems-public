# FAQ

**Is any product available to buy or deploy?**
No. Everything is IN DEVELOPMENT. There are no contracts or formal pilots.

**Is the source code public?**
No. This repository is documentation only.

**Does Praecura diagnose faults accurately?**
We make no accuracy claim. See [research and technical results](10-research-and-technical-results.md).

**Does your software control equipment?**
No. It is read-only toward equipment, and it is not a building management system.

**Is Brújula a fire, theft or life-safety alarm?**
No. Event sensors give notices. Nothing here claims to prevent loss.

**What does VERIFIED mean?**
Checked by running it, on a stated date and scope. See [status labels](status-labels.md).

**Which languages are the products in?**
