# Brújula Eudaimonia

**Status: IN DEVELOPMENT**

Eudaimonia is the general edition of [Brújula](02-brujula.md), for servers and workstations where a person wants a machine that explains itself and protects its own records.

## State

- A general-edition image has been built (October 2026).
- The common Brújula test suite passes (see [Brújula](02-brujula.md) for date and scope).
- Several integrity and recovery behaviours have been exercised in disposable laboratory environments. These are EXPERIMENTAL: laboratory results, not field results.

## Not yet proven

Operation with production keys, real boot on customer hardware, long-duration runs and any production use. No demand for this edition has been demonstrated.
